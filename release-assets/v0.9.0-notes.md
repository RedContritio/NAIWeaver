## v0.9.0 — Characters, Text Generation & SD-Card Export

### Characters (New)
- **Saved character library** — build reusable personas with split appearance buckets (base / face / hair / body) and a per-character closet of outfits. Each character is stored locally as one JSON file, with the closet kept separately so wardrobes stay portable and editable. Clothing lives in the closet, not on the character.
- **AI character generation** — a ✨ generator drafts a character and a starter wardrobe from a free-text vibe + era + location, with an optional artist-tag style field. Ships with ~50 historical era presets (Age of Ramesses through the modern day) for period-correct results, and a lean appearance-only prompt that emits canonical Danbooru tags instead of invented English phrases.
- **Wardrobe generator** — generates era- and vibe-appropriate outfits with garment-only tag scope and color discipline. Undergarment rules are now gender- and era-aware: a male historical character gets period base layers (loincloth, braies, linen undershirt) instead of feminine undergarment tags.
- **Outfit state** — each outfit tracks per-slot dressing state (intact, unbuttoned, open, lifted, pulled down, aside, around ankles, removed) with automatic concealment, so layered pieces only surface when the outer garment moves. The state panel is mobile-first with tap-to-open state pills.
- **Insert characters anywhere via autocomplete** — saved characters appear as `[Name]` and `[Name (Outfit)]` entries in the tag autocomplete, ranked above ordinary tags. Picking one expands into the full body + outfit tag block. An inline "honor outfit state" toggle renders the outfit at its current dressing state instead of the flat tag string.
- **Per-character & per-outfit negative tags** — attach negatives to a character or a specific outfit; they're routed automatically to the right negative-prompt field when the character is inserted, de-duplicated against what's already there.
- **Photoshoot mode** — pick a character + outfit, dress them in-place for the session, choose a style plus curated pose and environment presets, and generate — without disturbing the saved closet. The screen mirrors the main editor: a large image preview up top (tap for the full-screen viewer) and a pull-up Dress / Scene / Prompt drawer with a persistent generate/send bar. Generating here won't clobber your main-editor prompt, and the character's negative tags come along automatically.

### Text Generation (New)
- **NovelAI text models** — a new Text Gen tool with a continue-style input, model picker, full parameter controls (temperature, max length, top-P/K, repetition penalties), client-side stop strings, live streaming output, and a local history.
- **Reasoning mode** — for GLM models, an "enable thinking" switch surfaces the model's private reasoning block in a collapsible Reasoning section alongside the answer.

### Export & Sharing
- **Export to an SD card (Android)** — choose a removable-SD-card folder as your export target via the system folder picker. The grant survives reboots, and exports stream straight to the card through the Storage Access Framework, which plain file writes can't reach under Android scoped storage (#13).
- **Web image download** — generated images can now be saved on the web build via a standard browser download.

### Packs & Backup
- **Bigger .vpack backups** — packs now bundle your custom themes, gallery albums, and app/jukebox settings in addition to presets, styles, wildcards, references, vibes, and character presets. (Restart after importing settings/themes to fully apply them.) The settings blob is allowlisted, so a backup never carries your API key, PIN, or folder paths.

### Generation UX
- **Enable/disable vibes & references** — toggle a vibe transfer or director reference off without deleting it; disabled items are skipped at generation time.
- **Type exact slider values** — tap any slider's number to type a precise value, including beyond the visible range, NovelAI-style.

### Cascade
- **Multi-interaction beat slots** — a cascade beat can now hold multiple interaction tags at once (e.g. `source#hugging`, `target#hugging`, `mutual#holding hands`) instead of just one.

### Jukebox
- **Anime & game song categories** — new MIDI tracks across two new categories.

### Gallery
- **Fix Android image import stripping PNG metadata** — importing PNGs into the gallery on Android no longer destroys their NovelAI metadata. `file_picker 8.x` was silently JPEG-re-encoding every image pick on the native Android side (its `compressionQuality` parameter defaults to 30, which triggers `Bitmap.compress(JPEG, ...)` for any `image/*` MIME pick). The transcoded bytes arrived at the app as JPEG with the `tEXt`/`iTXt` PNG chunks already gone — including the NovelAI `Comment` JSON, `Description`, and `Software` tags. The fix passes `compressionQuality: 0` to short-circuit the re-encode and stream the original bytes through unchanged. NAIWeaver-exported PNGs now re-import with full metadata. The "(N converted to PNG)" status message should now only appear for genuinely non-PNG inputs (JPEG, WebP).

### Fixes
- **Touch scroll on long prompts** — a mouse wheel on Android no longer skips multiple lines in multi-line prompt fields (#14).
- **Inpainting & canvas** — interrupting a one-finger stroke with a second finger (pinch-zoom) no longer leaves the partial stroke on the mask or canvas.
- **Desktop window** — guard against an invisible window restored from stale saved bounds.

### Localization
- New strings localized for EN, JA, ZH (Text Gen panel, pack sections, character UI).

### Notes
