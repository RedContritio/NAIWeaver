## v0.9.0

### Gallery
- **Fix Android image import stripping PNG metadata** — importing PNGs into the gallery on Android no longer destroys their NovelAI metadata. `file_picker 8.x` was silently JPEG-re-encoding every image pick on the native Android side (its `compressionQuality` parameter defaults to 30, which triggers `Bitmap.compress(JPEG, ...)` for any `image/*` MIME pick). The transcoded bytes arrived at the app as JPEG with the `tEXt`/`iTXt` PNG chunks already gone — including the NovelAI `Comment` JSON, `Description`, and `Software` tags. The fix passes `compressionQuality: 0` to short-circuit the re-encode and stream the original bytes through unchanged. NAIWeaver-exported PNGs now re-import with full metadata. The "(N converted to PNG)" status message should now only appear for genuinely non-PNG inputs (JPEG, WebP).
